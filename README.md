# Power-BI-Sales-Shipment-Analysis-Dashboard
This project is an interactive Power BI dashboard developed to explore and analyze sales and shipment performance.
The dashboard covers:

📦 Boxes shipped by country
📈 Sales amount trends over time
🛍️ Product-wise shipment analysis
📊 Product-level sales contribution
💧 Waterfall analysis of amount changes
🌍 Country and product performance comparison

Tools & Technologies:
Power BI Power Query Data Analysis Data Visualization
